## 受控功能与故障验收

| 项目 | 已通过的验证 |
| --- | --- |
| 后端恢复 | 复用数据库创建新服务并执行恢复，沿用已保存的上游编号继续查询，最终完成，上游提交次数保持一次。原子改名后数据库尚未更新的结果可恢复。 |
| 提交结果未知 | 覆盖提交响应超时、派发中恢复及上游接受后本地保存编号失败。任务进入待核对状态，暂停后续派发。通过存储层核对操作关联已有任务或确认失败。 |
| 结果传输中断 | 注入流式读取错误后保留传输状态、清理临时文件，再次下载同一结果。验证两次内容下载对应一次上游提交。 |
| 上游记录丢失 | 以任务查询返回 404 模拟推理服务重启后的记录丢失，任务明确失败并保存原因，上游提交次数保持一次。 |
| 重复提交 | 同请求编号与参数返回同一任务，参数冲突返回 409。推理离线后仍可查询已接受的重复请求。并发写入同编号只产生一条记录。 |
| 队列 | 验证一个执行任务、五个等待位及超限返回 429，并发领取只有一个成功者。 |
| 缓存时限 | 将完成时间前移 86401 秒，回收后媒体返回 410，任务记录保留，视频地址隐藏。 |
| 缓存容量 | 将容量缩为 25 字节验证最早完成结果优先回收、任务记录保留及容量约束。读取中的媒体受到租约保护，容量不足时推迟传输。 |
| 媒体验证 | 合成 MP4 经过真实 FFmpeg/FFprobe 检查、下载、原子保存及 Range 206 验证，损坏视频进入失败状态。 |
| 进度与规格 | 默认进度零隐藏，有效正百分比保留，完成时显示 100。每个任务保留创建时的生成规格，历史任务恢复沿用原规格。 |
