# XYZenith Demo

交互式视频生成演示。首轮目标是在公网网页提交提示词，由实验室 A100 生成视频，页面播放结果并展示真实耗时。

代码仓库为 `lusunn111/XYZenith_Demo`，当前公开可见。前端、后端、推理适配和部署配置统一在本仓库维护。

## 部署分工

| 位置 | 职责 |
| --- | --- |
| 公网 VPS | 前端网页、任务接口、排队与状态、视频访问 |
| A100 服务器 | SGLang Diffusion 推理服务，本地模型、环境及缓存，视频生成 |
| 组内共享数据盘 | 视频原件及已有模型来源 |

GPU 服务器主动建立到 VPS 的反向连接。VPS 将一个完整生成任务交给一个推理实例。首轮使用单张 A100，后续接入其他实例时增加能力登记与健康检查。

## 代码布局

- `frontend/` 保存前端页面。
- `backend/` 保存 VPS 任务接口与任务管理。
- `inference/` 保存推理适配、模型配置和启动脚本。
- `deploy/` 保存 VPS、GPU 与连接配置模板。
- `docs/` 保存接口及部署说明。

前端和业务后端已实现，包含单任务执行、五个等待位、任务持久化、断线恢复、视频播放及缓存回收。模型文件和生成视频存放在部署环境，仓库记录版本、路径约定和复现步骤。

## 服务器规范

代码放在用户主目录的 `XYZenith_Demo` 项目中。2026-11-08 用户确认本地缓存方案，模型、环境与缓存进入本地盘 `~/.local/share/xyzenith`，视频原件保留在 `/data/Zhihao/XYZenith_Demo/outputs`。保留现有 `/data/Zhihao` 软链接映射。运行前检查 GPU 占用，并显式指定设备。

2026-11-07，通过 `IF-Lab_` 直连核实两张 A100-PCIE-40GB，卡间拓扑为 NV8。`/data` 为 NFS 共享存储，当时剩余约 19 TB，可写。A100 到 VPS 的反向隧道已建立并通过自动重连验证。GPU 占用和可用空间须在部署时重新查询。

首版模型为 MiniMax-H3，当前配置为 LightX2V 四步 LoRA（低秩适配权重）、480p、约 5 秒。运行环境固定为 SGLang 0.5.19-cu129，使用 GPU 0、单卡并行度、60 GiB 主机内存上限和 `--pin-cpu-memory false`。该配置已完成原生生成及公网双任务验收。开发与发布命令见 [部署说明](docs/deployment.md)，业务接口及故障恢复见 [后端说明](backend/README.md)，推理环境见 [推理说明](inference/README.md)，进度见 [待办清单](TODO.md)。

## 验证状态

2026-11-08，VPS 上 39 项后端测试通过，包含真实 FFmpeg 媒体解析与范围请求。A100 本地的 85 个基础权重文件及 LoRA 共 86 项摘要校验通过，隔离运行环境与 GPU 基础检查通过，关闭权重锁页后单卡服务已就绪。

2026-11-07 已部署网页及业务 API，浏览器通过受控接口验证提交、状态、播放、刷新恢复、过期与手机布局，并通过真实反向隧道验证隔离 CPU 测试任务及视频回传。2026-11-08 真实 H3 公网双任务验收通过，支持排队、刷新恢复、播放和下载。两次网页生成服务耗时分别为530.34秒和486.82秒，均输出864×480、约5.17秒视频。生成期间实际重启VPS后端后任务继续完成。完整口径见 [验收记录](docs/validation.md)。

单 A100 真实生成已跑通，双卡优化和 L20 接入保留为后续工作。资源评估、官方运行证据及交接步骤见 [H3 可行性与交接](docs/h3-feasibility-and-handoff.md)。
