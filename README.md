# XYZenith Demo

交互式视频生成演示。首轮目标是在公网网页提交提示词，由实验室 A100 生成视频，页面播放结果并展示真实耗时。

代码仓库为 `lusunn111/XYZenith_Demo`，当前采用私有可见性。前端、后端、推理适配和部署配置统一在本仓库维护。

## 部署分工

| 位置 | 职责 |
| --- | --- |
| 公网 VPS | 前端网页、任务接口、排队与状态、视频访问 |
| A100 服务器 | SGLang Diffusion 推理服务、模型加载、视频生成 |
| 组内共享数据盘 | 模型权重、虚拟环境、缓存和生成文件 |

GPU 服务器优先主动建立到 VPS 的反向连接。VPS 将一个完整生成任务交给一个推理实例。首轮使用一组 A100，后续接入其他实例时增加能力登记与健康检查。

## 代码布局规划

- `frontend/` 保存前端页面。
- `backend/` 保存 VPS 任务接口与任务管理。
- `inference/` 保存推理适配、模型配置和启动脚本。
- `deploy/` 保存 VPS、GPU 与连接配置模板。
- `docs/` 保存接口及部署说明。

目录随对应代码加入而创建。模型文件和生成视频存放在部署环境，仓库记录版本、路径约定和复现步骤。
