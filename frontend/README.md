# 前端工作台

采用 React、TypeScript 和 Vite，默认连接同源业务接口。界面包含提示词输入、随机种子、任务状态、视频播放与下载、实际规格与耗时。字体随构建产物提供，中文使用系统字体。

创作台采用深色与暖橙配色，提供三组示例提示词及静态灵感预览。模型与生成规格读取健康接口。生成阶段由任务状态驱动，百分比仅在上游提供真实进度时显示。支持键盘焦点、读屏状态播报和减少动态效果偏好。

`public/images/coastal-observatory.jpg` 为 2026-11-07 使用 ImageGen 生成的灵感封面，1500×844，约 282 KiB。页面标注“灵感预览 · 静态图”和“AI 生成灵感图”，实际任务结果通过视频播放器展示。

## 本地开发

使用 Node.js 22.12 或更新版本，在本目录执行。

```bash
npm ci
npm run dev
```

开发服务器将 `/api` 和 `/media` 转发到 `http://127.0.0.1:18000`。后端不可用时，页面显示连接状态。开发模拟接口通过健康响应中的 `mock: true` 显示明确标记。

## 构建与部署

```bash
npm run build
```

部署 `dist/` 静态产物，由 Nginx 同源提供 `/api` 和 `/media`。页面通过 `?job=任务编号` 恢复任务。业务接口字段见 `src/api.ts`。

客户端请求编号存入当前标签页会话，网络故障后的重试沿用该编号。页面刷新时恢复原任务状态，浏览器“提交至可播放”计时只记录当前页面实际发起的首次提交，刷新后的页面仅展示后端记录的阶段耗时。

构建命令同时执行严格 TypeScript 类型检查。端到端测试应覆盖离线、队列已满、任务恢复、提交响应丢失后重试、失败、缓存过期与移动端布局。
